## Failed Attempts
- `python test_asr.py` crashed with `UnicodeEncodeError: 'charmap' codec can't encode characters` — Windows console cp1252 can't print Thai text. Fixed by wrapping stdout in `io.TextIOWrapper(..., encoding="utf-8")`. Never print raw unicode transcript to default stdout on Windows without this wrapper.
- large-v3 download crashed: `OSError: [WinError 1314] A required privilege is not held by the client` on `os.symlink` — Windows needs Developer Mode or admin for HF hub symlink cache. Fix: set env var `HF_HUB_DISABLE_SYMLINKS=1` before download so huggingface_hub copies files instead of symlinking. Never assume HF cache symlinks work on plain Windows.
- `deepdml/faster-whisper-large-v3-turbo-ct2` load crashed: `OSError: [WinError 1314] A required privilege is not held by the client` on blob->snapshot link for `tokenizer.json`, even with `HF_HUB_DISABLE_SYMLINKS=1` set. Disabling symlinks does not fully fix all HF cache link ops on Windows for every repo — some repos still hit this on specific files. Never assume `HF_HUB_DISABLE_SYMLINKS=1` alone guarantees a clean download on Windows; may need per-repo retry or manual cache clear.
- `Qwen/Qwen3-ASR-0.6B-hf` load crashed: `RuntimeError: Unable to open file 'model.bin'` — repo is a native transformers checkpoint, not CTranslate2/ct2 format, incompatible with `faster_whisper.WhisperModel`. Never load non-ct2 repos via `WhisperModel` directly; would need a separate `transformers`-based loader, out of scope for faster-whisper-based bench.
